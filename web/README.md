# Upland web

The upland single-page application: React 19 + TypeScript on Vite, styled with
Tailwind v4 and shadcn/ui, routed with TanStack Router (file-based routes in
`src/routes/`), server data via TanStack Query. In production the build output
in `web/dist` is embedded into the `upland` binary; in development the Vite
dev server proxies `/api` to `cargo run`.

## Commands

- `bun install` — install dependencies (lockfile `bun.lock` is committed)
- `bun run dev` — Vite dev server on :5173, proxying `/api` to 127.0.0.1:8080
- `bun run test` — Vitest once; `bun run test:watch` for watch mode
- `bun run lint` — oxlint
- `bun run format` / `bun run format:check` — Prettier (incl. Tailwind class sorting)
- `bun run build` — typecheck (`tsc -b`) + production build into `web/dist`

## Testing

Tests live next to the code (`src/**/*.test.tsx`) and run in jsdom against the
rendered app root: the full `RouterProvider` + `QueryClientProvider` tree from
`src/test/harness.tsx`, with the `/api` boundary stubbed at `fetch`. Test
behavior users can observe (route outcomes, data rendering, error states) —
not component internals.

## Notes

- Routes are file-based; `src/routeTree.gen.ts` is generated by the TanStack
  Router Vite plugin and committed so `tsc -b` and `vitest` work without a
  prior dev/build run.
- Dark mode follows the OS preference (media-query theme); there is no toggle.
- Router and Query devtools render in dev builds only (`devtools` prop in
  `main.tsx`).
